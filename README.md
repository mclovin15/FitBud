# Gestionnaire d'Entraînement et d'Exercices

## Description
Un projet web développé en 2022 dans le cadre de mes études collégiales. L'application permet de consulter un inventaire détaillé d'exercices de musculation (incluant des images) et offre la possibilité aux utilisateurs de se créer des plans d'entraînement sur mesure.

## Fonctionnalités Principales
* **Catalogue visuel :** Consultation de l'inventaire des exercices disponibles avec un support visuel (images).
* **Gestion des exercices (CRUD) :** Ajout de nouveaux exercices à la base de données.
  * Modification des informations des exercices existants.
  * Suppression d'exercices de l'inventaire.
* **Programmes sur mesure :** Création et sauvegarde de plans d'entraînement personnalisés.

## Technologies Utilisées
* **Back-end :** PHP
* **Base de données :** MySQL
* **Front-end :** HTML, CSS (et JavaScript)
